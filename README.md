# 🕌 Prayer Times Bot

Бот времени намаза: 5 языков (EN, RU, UZ, TG, AR), всё на инлайн-кнопках.
Язык → мазхаб → город (пишется текстом с подтверждением, или геопозицией) → времена молитв → напоминания.
Кибла, Рамадан (сухур/ифтар), Джума, дата по хиджре, тихие часы, выбор «за сколько минут».
Работает в личке, в группах и в каналах. Есть поддержка (связь с админом) и админка.

## Запуск на Railway

1. Создай бота в **@BotFather**, скопируй токен.
2. Залей эти файлы (`bot.py`, `webapp.html`, `requirements.txt`, `Procfile`) в репозиторий GitHub. Все — в корень, рядом друг с другом.
3. Railway → **New Project → Deploy from GitHub repo**.
4. В том же проекте: **+ New → Database → PostgreSQL**.
5. Открой сервис с ботом → **Variables**:
   - `BOT_TOKEN` = токен от BotFather
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (ссылка на переменную базы)
   - `ADMIN_ID` = твой Telegram ID (узнать у @userinfobot) — включает админку
   - `CONTACT` = твой email или @username (по правилам геокодера OpenStreetMap)
6. Для мини-приложения: сервис бота → **Settings → Networking → Generate Domain**. Если Railway спросит порт, укажи `8080`.
   Бот сам узнает адрес (переменная `RAILWAY_PUBLIC_DOMAIN`), ничего вписывать не нужно.
   Без домена бот тоже работает, просто без мини-приложения: Кибла будет картинкой.
7. Deploy. В логах должно быть `Bot is ready` и `Mini app server on port …`. Напиши боту `/start`.

## Мини-приложение

Кнопка «📱 Открыть приложение» в меню бота и кнопка «🕌 App» рядом с полем ввода.
Вкладки: 🕌 Сегодня (таймер до намаза), 🧭 Кибла (живой компас с вибрацией), 📅 Календарь на месяц, 📿 Тасбих,
☰ Ещё: ✅ трекер намазов, 🌙 Рамадан, 🕌 мечети рядом (OpenStreetMap), 📖 99 имён Аллаха, 📲 на главный экран.
Тасбих и трекер хранятся в облаке Telegram у каждого пользователя. Оформление подстраивается под тему Telegram.
Живой компас работает на телефонах; в группах и на компьютере «🕋 Кибла» присылает картинку-компас.

## Напоминания

Два напоминания на каждую молитву: заранее (5/10/15/30 мин или выкл) и в момент намаза (вкл/выкл).
По умолчанию: за 10 минут и в момент намаза. Джума, сухур и ифтар — особыми текстами.

## Группы и каналы

- **Группа:** кнопка «➕ Добавить в группу» в меню. Бот здоровается и просит админов группы настроить его
  (язык → мазхаб → город ответом на сообщение бота). Менять настройки могут только админы группы.
  В настройках группы есть «📅 Расписание на день»: выкл / в момент Фаджра / после восхода.
- **Канал:** кнопка «📢 Добавить в канал». Бота нужно сделать админом с правом «Публикация сообщений».
  После добавления бот пишет в личку тому, кто его добавил, и настраивает канал оттуда.
  Позже — через «📢 Мои каналы» в меню.

## Поддержка

«💬 Поддержка» в настройках. Пользователь может прислать что угодно (текст, фото, видео, голосовое, файл…).
Админу приходит имя (кликабельное), @username, ID, город и язык, само сообщение и кнопки
«↩️ Ответить» / «👤 Карточка». Ответ (тоже любого типа) уходит пользователю от имени бота.
Важно: админ должен хотя бы раз нажать /start в боте, иначе Telegram не даст боту ему писать.

## Админка

Видна только тебе (кнопка «🛠 Админка» в меню или `/admin`):
статистика, география и языки, рассылка (всем / по языку / по стране, с предпросмотром и подтверждением),
поиск пользователя по ID, бан/разбан, тестовое напоминание, экспорт CSV, здоровье бота.
В статистике видно число групп, каналов и участников в них. Рассылку можно отправить только пользователям или ещё и в группы с каналами.

## Заметки

- Время считает API Aladhan. Метод расчёта подбирается по стране (словарь `METHOD_BY_COUNTRY` в `bot.py`), иначе — Muslim World League. Если в твоём регионе принят другой метод — поменяй там.
- Мазхаб влияет на время Аср (ханафитский = позже).
- Все тексты лежат в словарях `EN`, `RU`, `UZ`, `TG`, `AR` в `bot.py`. Узбекский и таджикский стоит показать носителю.
- Переводы 99 имён на узбекский и таджикский лучше показать знающему человеку.
- Единственное не-инлайн место: кнопка «Отправить геопозицию» — Telegram не умеет запрашивать геопозицию инлайн-кнопкой.
